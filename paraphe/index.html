Installer votre signature

Gmail

  1. Cliquez « Copier la signature ».
  2. Gmail → ⚙️ Paramètres → Voir tous les paramètres.
  3. Section « Signature » → Créer → collez (Ctrl/Cmd + V).
  4. Enregistrez en bas de page.

Outlook

  1. Copiez la signature.
  2. Paramètres → Comptes → Signatures.
  3. Nouvelle signature → collez.
  4. Choisissez-la par défaut, enregistrez.

Apple Mail

  1. Copiez la signature.
  2. Mail → Réglages → Signatures → +.
  3. Décochez « Toujours utiliser ma police par défaut ».
  4. Collez dans la zone de signature.

# session-handoff

Mod لـ Claude Code (مبني ومختبَر على الإصدار 2.1.330) يرسل رسالة تسليم منظمة من جلسة إلى جلسة أخرى، بعد أن تختار الجلسة المستقبلة وتراجع الرسالة بنفسك.

## الاستعمال

1. اكتب `/handoff` في الجلسة المرسِلة.
2. تُفتح لوحة «تسليم الجلسة». يسرد الـ Mod الجلسات المتاحة (عبر أداة `ListAgents`)، ويعدّ مسودة من ستة حقول: **الهدف، ما أُنجز، القرارات، مسارات الملفات، الخطوة التالية، معيار القبول**.
3. اختر الجلسة المستقبلة من القائمة، وعدّل الحقول كما تشاء.
4. اضغط **إرسال**. لا يُرسَل شيء قبل هذا الضغط.

## الضمانات

- **لا يُرسَل سجل المحادثة:** تُعدّ المسودة بـ `$.model.fork`، وهو استدعاء جانبي فوق سجل الجلسة نفسها. لا يغادر الجلسةَ إلا الملخص. كل حقل محدود بـ 1200 حرف، والرسالة كلها بـ 6000 حرف.
- **لا أسرار:** تُستبدل بـ `[REDACTED]` مفاتيح API (`sk-…`، `ghp_…`، `AKIA…`، `xox…`، `AIza…`)، ورموز JWT وBearer، والمفاتيح الخاصة، وقيم `password=`/`token=`/`secret=`، وبيانات الدخول داخل الروابط. يجري الإخفاء عند إعداد المسودة ومرة ثانية عند الإرسال.
- **لا تكرار:** لكل رسالة معرّف (SHA-256 للمستقبِل والمحتوى) يُحفظ في `$.store` مدة سبعة أيام. إعادة إرسال المحتوى نفسه إلى الجلسة نفسها تُرفض، والضغطة الثانية أثناء إرسال جارٍ لا تفعل شيئًا. في الجلسة المستقبلة، تُحذف الرسالة المستلمة مرة ثانية بالمعرّف نفسه قبل أن يقرأها النموذج.
- **لا حلقات رد آلي:** لا يرسل الـ Mod شيئًا من تلقاء نفسه، فالإرسال يحتاج دائمًا ضغطة من إنسان. يرفض الـ Mod أي `SendMessage` يكتبه النموذج ويحمل ترويسة التسليم، فلا يستطيع النموذج إعادة توجيه التسليم ولا الرد به آليًا. وتطلب الرسالة نفسها من الجلسة المستقبلة ألا ترد آليًا.

يجب تثبيت الـ Mod في الجلستين ليعمل حذف المكرر ومنع التوجيه في الجهة المستقبلة.

## الاختبارات

```sh
claude plugin validate ./session-handoff
claude plugin test ./session-handoff
```

## تعطيل الـ Mod

- **لجلسة واحدة:** شغّل Claude Code من دون `--plugin-dir ./session-handoff`، أو مع `claude --safe-mode`، فيبدأ بلا أي إضافات.
- **إن كان مثبتًا كإضافة:** `claude plugin disable session-handoff`، ثم `claude plugin enable session-handoff` لإعادة تفعيله. أو من داخل الجلسة: `/plugin`، ثم اختر session-handoff، ثم Disable.
- **نهائيًا:** احذف مجلد الـ Mod، أو `claude plugin uninstall session-handoff`.
- **مسح ذاكرته:** المعرّفات المحفوظة في `$.store` تخص الـ Mod وحده، ولا تؤثر في شيء بعد تعطيله.
